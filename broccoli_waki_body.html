大きな花蕾を切った日。
手には、ずっしり重い緑のかたまり。
残った株を、このまま引き抜いてしまっていいのでしょうか。


答えは、切った日から2〜3週間の株の中で見つかります。


  • 切った直後の株に、何が残るか

  • 脇から出る花蕾は、いつ採れるか

  • 手を入れる日と、入れない日

  • 株を抜いたほうがいいケース



切った日の株には、まだ続きがある


株のてっぺんで最初に育つ大きな房は、頂花蕾という名前です。
切ったあとの株には、葉のつけ根に、小さな芽が並んでいます。


この芽が育つと、脇花蕾（側花蕾）になります。
頂花蕾より小ぶりでも、味は同じブロッコリーです。


・切った日 → 葉のつけ根に、小さな芽が見える
・1週間後 → 芽が伸びはじめる
・2〜3週間後 → 小さな花蕾の形になる




脇の花蕾は、10cmが目安


脇花蕾は、ふつう直径10cm以下で、頂花蕾よりかなり小さめです。
10cm以上に育てば、頂花蕾と同じ扱いで売られることもあります。


家庭で食べる分には、サイズより粒の締まりです。
粒がそろって固いうちに、切ってください。


・5cm前後 → ゆでて添える分には十分
・10cm前後 → 頂花蕾に近い食べごたえ
・粒がゆるむ → 黄色い花が出る前に切る




本数は、2本に絞ると太くなる


脇の芽は、放っておくと10本ほども出ることがあります。
数が多いほど、1本ずつは細く小さくなります。


そこで、元気な芽を2本ほど残して、あとは早めに外します。
2本に絞った株のほうが、肥大が進みやすいとされています。


・残す → 太くて、角度のよい芽を2本
・外す → 細い芽、混み合った芽
・外す時期 → 小さいうちに、指でかき取る





切ったあとの追肥は、1回足す


花蕾を切るまでに、株は養分をかなり使っています。
脇花蕾を太らせるなら、切ったあとに追肥を1回足すと続きが楽になります。


・時期 → 切ってから、芽が動きはじめる頃
・場所 → 幹のすぐそばではなく、外側の葉先の下あたり
・寒い時期 → 肥大がゆっくりなので、回数を増やす考え方もある


種苗会社の栽培ガイドにも、低温期は肥大が途切れないよう追肥の回数を増やす、とあります。
ただし、量を増やしすぎると、かえって株が弱るので、袋の表示どおりが基本です。




寒くなると、脇花蕾はどうなる？


12月に入って冷え込むと、芽の伸びはゆっくりになります。
霜に当たる回数が多い地域ほど、脇花蕾は小さく止まりやすくなります。


・暖かい地域 → 冬のあいだも、ゆっくり育つ
・冷える地域 → 小さいまま止まることがある
・霜が続く夜 → 不織布で守ると、傷みを減らせる





株を抜いたほうがいいのは、どんなとき？


脇花蕾を待たず、株を片づけたほうがいい場合もあります。


・葉に黒い斑点や、べたつきがある → 病気が広がる前に抜く
・根元が柔らかく、株がぐらつく → 根の傷みなので、無理に残さない
・次の作付けを急ぎたい → 脇花蕾は、あきらめる
・アブラナ科が続いている畑 → 株を残さず、土をやすめる


抜いた株は、畑の隅に積まず、袋に入れて処分すると安心です。




このやり方が合わない畑


この記事は、秋に植えた、ふつうのブロッコリーの話です。
スティック型の品種や、寒さの厳しい地域では、同じ運びにならないことがあります。


・スティックタイプ → もともと脇から採る前提の品種
・氷点下が続く地域 → 脇花蕾は期待しにくい
・苗を植えたのが遅かった年 → 頂花蕾が小さく、脇花蕾もさらに小さい


収穫の時期が読めないときは、県の栽培暦を開いてみるのが早道です。
