深く植えたほうが根づく。そう思って土をかぶせた株が、春にいちばん実をつけません。

①👑 イチゴには、埋めてはいけない一点があります

イチゴの株元を見ると、葉の付け根が集まった短い塊があります。ここを「クラウン」と呼びます。王冠に似ているから、という名前です。

ここは根でも葉でもありません。新しい葉と、花の房が出てくる場所です。

野菜の多くは、深植えが致命傷になりません。トマトは茎から根が出るので、むしろ深めに植えることがあります。イチゴが違うのは、伸びる場所が株元の一点に集まっていることです。

そこを埋めると、出口をふさぐことになります。

②🕳️ なぜ、クラウンを埋めると育たないのか

新しい葉も花も、そこからしか出ない

イチゴは、クラウンから順に葉を出します。秋に出た葉が冬を越し、春にその株が花を咲かせます。

クラウンが土に埋まると、そこから出ようとする芽が土を押しのけることになります。押しのけられれば遅れるだけで済みますが、押しのけられなければそこで止まります。

株が枯れなくても、春に出る花の数が減ります。収穫がゼロになるより、「なんとなく少ない」で終わることのほうが多いはずです。原因が分かりにくいのは、そのためだと思っています。

埋まった株元は、乾かない

もう一つあります。土をかぶせると、株元が常に湿った状態になります。

株元が濡れたままだと、傷んだ葉や枯れた葉がそこに残り、腐りの起点になりやすくなります。秋は雨が続く時期でもあります。

③📏 では、浅ければいいのか

浅すぎると、根が乾く

逆に浅すぎると、根鉢の上面が空気に触れます。イチゴの根は浅く広がるので、そこが乾くと水を吸えません。

植えた直後に葉がしおれる株は、根が乾いていることが多いです。

基準は「クラウンの下端が、土の表面と同じ高さ」

クラウンの下のふくらみが土に隠れない位置に置きます。深くも浅くもない線がここです。

📌 ・クラウンが土に隠れている → 深すぎ。そこから腐ります

📌 ・根鉢の上面まで浮いている → 浅すぎ。根が乾きます

確かめ方は、真上から見ることです。

葉の付け根が、1本残らず見えていれば正解。1本でも土に隠れていたら深すぎます。その日のうちに掘り直してください。翌日でも遅くはありませんが、根が動き出すほど植え直しの代償が大きくなります。

土は、根鉢の側面に寄せます。上からかぶせません。かぶせた土が、そのまま株元に落ちます。

④🧭 もう一つ ―― 向きで、収穫のしやすさが変わります

苗をよく見ると、株元にランナー（親株から伸びたつるの跡）が残っています。切り口が短く出ていることが多いです。

イチゴは、このランナーの反対側に花の房が出ます。

つまり、ランナーの跡を内側（中心側）に向けて植える。プランターなら中央へ、畝なら畝の芯へ向けます。すると実は外へ垂れます。

これは収穫のしやすさだけの話ではありません。実が葉の下にもぐらないので、見つけやすく、色づきも確認しやすくなります。実が地面に触れる時間も短くなります。

知らずに植えると、実が全部内側を向いて葉の下に隠れます。

⑤🗓️ 植える時期を外すと、深さを合わせても遅れます

イチゴは、気温が下がって日が短くなると、株の中で花のもとを作ります。花芽分化と呼ばれる動きです。

一般には、この分化が進んだ苗を、10月の中ごろから下旬に植えるのが目安とされています。地域差があるので、日付そのものより「朝晩が冷えはじめたころ」で見るほうが確実です。

📌 ・早すぎる → 気温が高いうちに植えることになり、株が葉ばかり茂ることがあります

📌 ・遅すぎる → 根が広がらないまま冬に入り、春の立ち上がりが遅れます

深さを合わせても、時期がずれれば結果はずれます。

⑥🩹 深く植えてしまったときは

気づいた時期で、できることが変わります。

📌 ・植えた直後 … 抜いて植え直せます。根鉢を崩さなければ影響は小さく済みます

📌 ・数週間以内 … 株元の土を、手で軽く払います。掘り返すより、かぶった分を取り除くほうが根を傷めません

📌 ・冬に入ってから … 動かさないほうがよいと思っています。根を切る代償のほうが大きくなります。株元の土を払うだけにとどめます

どの時期でも共通するのは、株元を見えるようにすることです。埋め直すのではなく、出すのが直し方です。

⑧ ✅ まとめ

📌 ・イチゴの株元にある「クラウン」は、新しい葉と花が出る一点

📌 ・埋めると、芽が遅れるか止まる。さらに株元が湿って傷みやすくなる

📌 ・浅すぎると根が乾く。基準はクラウンの下端が土の表面と同じ高さ

📌 ・確かめ方は真上から。葉の付け根が1本残らず見えていれば正解

📌 ・ランナーの跡の反対側に実が出る。跡を畝の内側へ向ける

📌 ・当日なら掘り直す。時間が経っていたら、掘り返さず株元の土を払う

ここまでは、植えるところまでの話です。

イチゴは、植えたあとも決まることが残っています。冬のあいだ葉をどこまで残すか、春に花が咲きはじめてから何をするか。深さと向きを合わせても、そこで差がつきます。

10月の植え付けから翌年の苗づくりまでを、ひととおり並べたものがあります。
